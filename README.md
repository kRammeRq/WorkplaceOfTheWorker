# WorkplaceOfTheWorker
Рабочее место кассира
Реализует 3 основные функции:
1) Открытие смены (считывает Имя кассира открывающего смену, количество наличных денег в кассе на момент открытия)
2) Закрытие смены (выводит статистку по смене, на какую сумму было продано товаров за наличные деньги и по банковской карте, а также сколько осталось наличных в кассе, итоговая вырочка и имя кассира)
3) Дабавление чека (формирует чек, считывая какое количество каких товаров было продано, способ оплаты и сумма оплаты, после чего печатает чек)

В products.json харнится бд продуктов с их описанием(название, штрихкод, цена).
